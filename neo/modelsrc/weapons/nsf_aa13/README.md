# v_nsf_aa13 with segmented reloads - research branch

Decompiled from the shipped viewmodel and recompiled with the AA13 plan's partial, resume and
draw-resume reload sequences (`segments.csv`, rows `aa13.*`). Built with ntre's
`proposals/0057-reload-cue-timing/tools/` and studiomdl (MDL v48; animations over 120 frames are stored in
30-frame sections, as studiomdl does by default).
