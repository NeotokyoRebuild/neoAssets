# v_jinrai_jittes with segmented reloads - research branch

Decompiled from the shipped viewmodel and recompiled with the Jitte plan's partial, resume and draw-resume reload
sequences (`segments.csv`, rows `jitte.*`, shared by the Jitte and Jitte scoped; frame counts resolved on the
Jitte, each model built from its own animations). No slap: partial cut f66 in the hold after the seat, 11-frame
straight exit; resumes reach the insert grab f52 (after the drop) or the bolt grab f78 (after the seat, dry).
Built with ntre's `proposals/0057-reload-cue-timing/tools/` and studiomdl (MDL v48).
