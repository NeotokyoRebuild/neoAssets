# v_jinrai_pz with segmented reloads - research branch

Decompiled from the shipped viewmodel and recompiled with the PZ plan's partial, resume and
draw-resume reload sequences (`segments.csv`, rows `pz.*`). Built with ntre's
`proposals/0057-reload-cue-timing/tools/` and studiomdl (MDL v48; animations over 120 frames are stored in
30-frame sections, as studiomdl does by default).
